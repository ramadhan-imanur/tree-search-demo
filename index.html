Graf rantai lurus (bamboo graph) tanpa cabang alternatif (\(\deg(v) \le 2\)).

Status: SOLVED

Status: SOLVED

Begitu arah menuju solusi mulai jelas (\(\bar{\mathcal{H}} < \tau\)), algoritma langsung beralih ke penelusuran mendalam (DFS) menuju target 24.

Rumus Matematis yang Digunakan

Landasan Teori

1. Teorema Invarian Pohon (Epp, 2020)

$$T \text{ adalah pohon} \implies |E| = |V| - 1$$

Setiap pohon dengan \(|V|\) verteks selalu memiliki tepat \(|E| = |V| - 1\) edge dan tidak memuat sikel.

2. Entropi Shannon Ternormalisasi (Cover & Thomas, 2006)

$$\bar{\mathcal{H}}(s) = -\frac{1}{\ln k} \sum_{i=1}^{k} \pi_\theta(a_i \mid s) \ln \pi_\theta(a_i \mid s) \in [0, 1]$$

Mengukur tingkat ketidakpastian pilihan aksi (\(k = |\mathcal{A}(s)|\)) untuk menentukan kapan harus beralih antara mode penelusuran melebar (BFS) dan mendalam (DFS).

3. Kriteria Pemangkasan Dini (Early Backtracking)

$$\Delta V(s, a) = V_\phi\big(\mathcal{T}(s, a)\big) - V_\phi(s) < -\delta$$

Membatalkan penelusuran cabang lebih awal saat penurunan evaluasi keadaan (\(\Delta V\)) melebihi batas toleransi parameter \(\delta\).

4. Bilangan Siklomatik Graf (Euler & Kirchhoff)

$$\mu(G) = |E| - |V| + 1 = 11 - 8 + 1 = 4$$

Jumlah sikel independen dalam graf terhubung \(G\). Nilai ini sama dengan banyaknya edge yang harus dihilangkan agar graf terhubung berubah menjadi spanning tree (\(|E \setminus E_T| = 4\)).
